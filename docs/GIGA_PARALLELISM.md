profile is TWO implementation instances: primary recovery/core lane and an isolated
colleague-interface lane. This is a resource choice, not a topology/provider ceiling.
Additional active worktrees wait; branches and original artifacts outlive retirement.

escaped processes stopped. No automatic source reset or branch switching.

implementation. Integration has ONE owner at a time (Root initially). Primary may

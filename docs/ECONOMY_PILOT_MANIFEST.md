## Frozen design and budget

per task. Then 4 untouched transfer runs: one new task per family, one fresh
run per policy. Total12; no enlargement for significance. Each run has8 provider
requests maximum and300s checkout-managed wall deadline (total upper bound60min

builds, network commands, delegates or RRC. Reviewer acceptance allowance5min/run;

Incomplete/failed/unknown runs remain denominator, not replacement runs. No provider
seed is available. Supervisor gpt-6.1-sol medium; assigned sessions same configured
provider/model/effort. No colleague provider calls permitted in assigned sessions.
Supervisor orchestration usage is separately reported, not silently attributed as
zero or added to one arm. No review-of-review or additional qualification ceremony.

Both arms use the identical committed `programs/economy_pilot.lua`, helper,
native executable and tool access. Source base is the commit containing this
manifest/workflow (exact full hash frozen into each local config before dispatch);
native release/arco qualification698ff4a, Lua confirmed-write fix abbd021/7cbc088.
Record SHA256 of executable, workflow, helper and each config; native source commit
is not itself a certification. Same context management: fresh contexts, no
compaction/selection/archive during assignments. Same feedback and original/audit/
complaint capabilities; every request has usage/audit-tail records. Missing usage,
replay latency and provider CPU are unavailable, not zero.

Only policy difference: baseline ordinary coding/inspection workflow with all8
attempts available; candidate bounded-first targeted searches/ranges, expansion
when question unresolved, concise working map/source locators. No compulsory
read cap, utility score or approval gate. Both may refine with the same attempts.
No cross-arm solutions, outputs or acceptance feedback delivered to other runs.

checkout users stopped; no primary checkout switching or worktree per candidate.
Branches/configuration/attempt records retain parent/effective identities; pool

Development order (counterbalanced): A-r1 baseline then bounded-first;

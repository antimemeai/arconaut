## Operating envelope

Before a unit, retain a concise source-grounded subplan: purpose, invariant,
relevant literature/reference consequence, direct failing oracle, useful delivery,
implementation allowance, hardening allowance and next action on exhaustion.
Use existing notes/issues/audit; no new certification ledger.

Default whole-unit allowance90minutes wall including source research/build/provider
waiting. Choose a smaller allowance for a smaller unit; splitting needs a genuine
independent behavior, not a budget reset for the same failed task. Within the unit,
hardening is at most25minutes: layer1 remediation tasks/fix; layer2 one recheck/fix;
never layer3. Explicit new operator scope can revise allowances. Do not waste the
whole allowance when direct evidence already settles the unit.

Existing passed checks stay settled unless relevant changes or defect evidence
warrant the affected oracle. Consequential colleague review is occasional and
scoped; one recheck can examine concrete fixes. No reviews of reviews, consensus
hunt, new “certified” tags or full-profile reruns merely for confidence. Native
lifetime/buffer changes get relevant sanitizer cases; portable changes get affected
Neuroses checks at useful boundaries. Mutations remain deferred/fleet-only.

At the bound, retain an honest state: ship qualified useful unit, retain unsafe
candidate inactive, revert that candidate or defer with concrete blocker and move
to independent work. Expired budget does not establish correctness. Do not grow a
unit's acceptance scope retrospectively. Fresh sessions/branches do not reset it.

# Context economy: measured policy trial

Operator2026-10-06: retain metrics and adapt to their evidence. Aphorisms are
not decision evidence. This is an amendment to the post-B1 interstitial, not
a new gate/platform or a claim of demonstrated improvement. Common instrumentation
is already delivered; do not recertify it. Read with USEFUL_WORK_INTERSTITIAL_SUBPLAN.

## First question and comparison

Does bounded-first information gathering deliver equally correct useful work
with less total resource use than the present workflow given extra attempts?
Compare one declared policy difference first: targeted searches/range reads,
expansion when the immediate question remains unresolved, and a concise working
map with original locators. Keep context-management settings common unless the
comparison explicitly evaluates a complete read+compaction policy; don't attribute
a combined change to one component. No universal per-paragraph utility scorer.

Before dispatch, write the task instances/independent behavioral oracles, source
bases, complete effective programs/settings, permitted edit surface, colleague
policy and fixed resource/attempt envelope into the experiment manifest. Both
arms receive identical common audit/repair capabilities and source access.
Counterbalance execution order; reset contexts/checkouts between attempts; no
leakage of another arm's solution or feedback. Record unavailable provider
seeds as unavailable, not imaginary controlled randomness.

Use a small fixed initial batch spanning at least two useful task families
(e.g. locating/repairing a code mechanism and recovering/applying a prior
constraint), with paired task instances and independent repeat runs under each
policy. Reserve untouched subsequent tasks for transfer. Choose the concrete
count/resource cap before dispatch based on actual call/latency costs; no
open-ended collecting until significance. Publish the count and its limitations.

## Retained outcomes and attribution

Record per actual attempt: task/family/repetition IDs, policy/candidate/parent,
source/program/configuration/model/provider identity, execution order, original
audit locators, correctness against independent behavior, unresolved work,
consequential omissions/regressions, follow-up retrievals, all available usage
(input/output/cached separately), elapsed phases, compile/RRC costs, human
steering/review/rescue and failure/unknown dispositions. Missing usage is not
zero. Keep failed/incomplete runs in the denominator. Preserve the actual outcome
records separately from model interpretations; reference ignored sensitive audit
locally rather than publishing private traces.

Recovery is an observed cost, not automatic proof that a summary was bad; a new
question can legitimately require originals. A negative colleague review is not
automatically wasted. Resolve reasons from the question/trace where possible;
otherwise mark attribution uncertain. Shrinking live input does not establish
cheaper native audit replay. A faster incorrect run is not an efficiency win.

## Statistical basis and adaptation

Show paired per-task differences and the distribution across repeats. Aggregate
uncertainty at the task/block level, not by pretending repeated requests or
multiple runs of one task are independent tasks. Report effect sizes and
uncertainty/ranges for correctness, resources, latency and interventions separately.
Predeclare any inferential method/assumptions; a tiny task set can support only
weak generalization. No arbitrary combined utility score or retrospective
exclusion of inconvenient failures.

At the end of the declared batch: keep, revise or drop the policy using those
outcomes. A correct useful product can ship independently of uplift. If benefits
are unclear, say inconclusive and retain the results. A revised policy gets a
new candidate/manifest and fresh assignments; adaptively reused tasks become
development data. Record why it changed and test transfer on untouched work.
No success claims from the model's explanation of its own efficiency. No
certification doom loop, automatic enlargement of budgets, or tuning judges
until the preferred policy wins. Giga remains a later campaign.

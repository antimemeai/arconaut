# computational-review-template

a staged actor/critic/validator protocol, evidence schemas and static viewer

Role: research workflow skill/template and static evidence viewer. Runtime: Markdown, JavaScript, Python notebook examples.

Pinned source: [https://github.com/AllenNeuralDynamics/ComputationalReviewTemplate](https://github.com/AllenNeuralDynamics/ComputationalReviewTemplate); revision/version `7312d15c12443031d9806a0550a4e665bd45ca92`.

Host coordinator loads role skills; MyST transforms files into a widget. No provider/agent scheduler source.

Consumes host delegation, artifact/version, execution, literature APIs and MyST; does not own the host engine.

Inspection: orchestrator v29 role/continuation/gate protocols, evidence validator specification and evidence-explorer loader/view

Limits of this study: Host enforcement, provider loop, original app database and runtime tests are unavailable.

## Actions

### generate_plan(plan_content=...) / update_step_status

Surface: Documented host coordinator calls.

Input: Validated scope plan entries and step state

Result: External plan/step status

Lifecycle: Prescribed external memory across compaction; host owns lifetime and approval

Authority: Coordinator; initial approval and exceptional signoff are authored requirements

Evidence: [e1](#evidence-e1), [e2](#evidence-e2).

### delegate_to(agent=..., task=...) / send_message

Surface: Documented host delegation/message API.

Input: Role, skills, explicit artifact/version inputs and complete task string

Result: Child findings, gate JSON, artifact/version handles

Lifecycle: New independent-validator and bounded-continuation frames; actors receive fixes

Authority: Host API; prompt-defined separation, no enforcement source

Evidence: [e1](#evidence-e1), [e2](#evidence-e2).

### section_NN_evidence_package.json

Surface: Produced evidence artifact contract.

Input: Findings/source sentences/DOIs/access labels; conflicts, figures, gaps

Result: Per-section packages consumed by static viewer

Lifecycle: Files can survive context; optional aggregate does not drive viewer

Authority: Reviewer/curator authors; build file scope

Evidence: [e4](#evidence-e4), [e5](#evidence-e5).

### Evidence Explorer directive + filters

Surface: Implemented static build transform and UI.

Input: Evidence directory/height; query/section/tier

Result: Loaded records; filtered first200 findings

Lifecycle: Rebuilt from files; no live DB service; fixed section range

Authority: Build filesystem access and public browser

Evidence: [e5](#evidence-e5), [e6](#evidence-e6).

### gate_evidence_compliance.json

Surface: Authored validator result schema.

Input: Evidence records, DOI metadata and scoped parameters

Result: Checks/counts/failures and aggregate gate

Lifecycle: Saved gate and bounded fix loops; prescribed downstream block on fail

Authority: Separate validator frame; exceptions via signoff

Evidence: [e7](#evidence-e7), [e3](#evidence-e3).

## Axis definitions

- **Files** (`filesystem`): Read/search/edit/patch files exposed to a model or programmable client.
- **OS programs** (`processes`): Execute OS programs; distinguish shell-only from PTY/streaming/ongoing handles and lifetime control.
- **Code actions** (`code_actions`): Model-authored executable programs or code actions compose tools, not merely JSON calls to fixed tools.
- **Kernel** (`persistent_kernel`): Interpreter/kernel state persists across actions; record owning process, lifetime, restart and serialization limits.
- **Standing DB** (`standing_database`): Model/program-accessible standing structured/queryable state; distinguish evidence DB/service from internal hidden storage or remembered text.
- **Workflows** (`workflow_programming`): Executable/declarative workflows or strategy programs are exposed for composition/replacement; distinguish editable prompts.
- **Models** (`multi_model`): Multiple providers/models, routing or switching; do not infer simultaneous collaboration from provider choice.
- **Peer chat** (`live_collaboration`): Addressed messages between independently working participants; inspect busy-target delivery, visibility and ownership.
- **Concurrency** (`concurrent_work`): Multiple active operations/children/participants or long-running work with meaningful handles/results.
- **Steer/interrupt** (`steering_interrupt`): Input/steering during work and actual cancellation/interruption semantics, not UI acknowledgement alone.
- **Turn program** (`turn_redefinition`): Turn/continuation/context scheduling program can change; inspect activation boundary and old work.
- **Compaction** (`compaction`): Managed context transformation strategies, triggers, actual retained/discarded material and tool protocol pairing.
- **Repair** (`context_repair`): Retrieve originals/lineage to repair omitted or corrupted active context; transcript resume alone is not enough.
- **Original audit** (`original_audit`): Retention of original captured provider/program/transformation IO and failures; distinguish transcript, summaries, clipped output and artifact provenance.
- **Audit query** (`audit_query`): Agent/program-usable query/search/retrieval of the retained audit corpus with explicit scope.
- **Hot change** (`hot_change`): Definition/config/plugin changes during operation; distinguish next call/turn/restart, active frames, and executable replacement.
- **Rebuild continuity** (`rebuild_continuity`): Actual harness executable rebuild/replacement and re-inhabitation with context/identity/work retained; transcript resume is partial.
- **Remote** (`remote_services`): Direct remote execution/service APIs and reconnect/session semantics; describe consumer versus governor boundary.
- **Self-improve** (`self_improvement`): Dedicated executable policy/harness/experiment change-and-evaluate machinery; generic file editing alone does not establish autoresearch governance.
- **Complaints** (`complaints`): Model-invokable complaints/bug reporting with captured state and follow-up; distinguish operator-only /bug or bare issue creation.
- **Authority** (`authority`): Standing execution/tool authority and model agency, approval defaults/overrides, program modification rights.
- **Evaluation** (`evaluation`): Evaluation/test/oracle mechanisms and real fault classes observed in source; test quantity is not correctness evidence.
- **Time/order** (`time_order`): Wall/monotonic time, deadlines, causal/order identity or restart/paused-time semantics where exposed.

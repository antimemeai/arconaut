## restate-sdk-python

The Python SDK supplies durable context primitives, not a coding-agent loop or persistent Python kernel. run/run_typed asks the protocol VM for a result handle and schedules a closure only when no recorded result is replayed (python/restate/server_context.py:916–984). The action executes first; only afterward does the SDK serialize and propose completion (846–912). Thus a recorded result can avoid rerunning the closure, while an external effect before settlement needs idempotency/reconciliation.

Object/workflow state and typed calls/sends are server-owned; awakeables, promises and addressed one-shot signals expose explicit identities (768–807,993–1061,1230–1277). Teardown waits protocol input close, flushes/closes output, then signals attempt-finished and cancels its task set. A synchronous action runs in an executor thread, and canceling its Future does not establish physical stop (420–448,603–646,846–868). Journaled wall time and seeded UUID/RNG are replay primitives, not resident continuity.

## restate-sdk-rust

The Rust SDK is a compiled service/client composition surface. Its RunFuture asks the VM whether to ExecuteRun, executes a closure, proposes serialized success/failure, then waits for a durable result (src/endpoint/context.rs:1016–1118). The public contract requires immediate await and forbids context calls inside the closure to avoid nondeterministic journal interleaving (src/context/mod.rs:898–973). Retry policy explicitly warns actual attempts/duration can exceed configured limits because closure execution precedes result receipt (src/context/run.rs:94–115). This is not atomic settlement of arbitrary external effects.

Typed calls carry service/object/workflow keys and idempotency/scope; virtual objects serialize but cyclic request waits can deadlock. Named one-shot signals address invocation ID/name (context/mod.rs:413–471,566–608,830–867). Connection drain/replacement overlaps transport sessions and test code reaps owned sockets/drivers, a meaningful lifecycle primitive that does not rebuild/re-inhabit an agent (tests/tunnel_handover.rs:24–111). Captured fake ingress transport checks wire data; it does not validate server replay or third-party effects (tests/ingress_client.rs:38–98). ## restate

Restate is a shared durable service governor; a consuming Arconaut should keep its own client boundary separate. Ingress resolves public targets and routes call versus send, preserving idempotency/invocation IDs and delayed202 acceptance (crates/ingress-http/src/handler/service_handler.rs:130–154,284–368). Invoker attempts stream stored state/seed/journal to a separate SDK deployment. SDK run completion arrives as a raw notification proposal; state-machine processing stores command/result bytes at exact indices with state/outbox effects (invoker runner:307–375,998–1037; state_machine/entries/mod.rs:355–414; set_state_command.rs:35–52; call_commands.rs:96–151). These are platform effects, not atomic settlement of arbitrary external closure activity.

Manual pause preserves journal, aborts running attempt and discards suspended wait state so replay recomputes it. Current-attempt fencing drops stale writes before they enter durable log. None proves a third-party request physically ended. Resume can explicitly repoint pinned deployment, checked at log position for existence/protocol compatibility, without checking semantic compatibility of a changed workflow program (manual_resume.rs:68–101,187–227).

## jido

Jido keeps immutable agent decisions and runtime effects separate, while allowing individual action modules to be effectful. `cmd` hooks normalize instructions and delegate a strategy; the server routes signals and interprets directives (`agent.ex:904–957`, `directive_executors.ex:74–116`). Supervised dispatch may be fire-and-forget and queue overflow drops directives. The protocol explicitly warns that hard stop can orphan async work (`directive_exec.ex:1–65`).

Its append-only Thread is a better starting point than a mutable prompt buffer. Hibernate flushes the thread before checkpoint; thaw requires the recorded thread revision and rejects missing/mismatching originals (`persist.ex:165–180,408–480`). The file adapter's temp/rename checkpoint and entry-then-metadata append are storage mechanisms, not external-effect transactions or a claim to power-loss durability. RuntimeStore ETS survives its API process but not the owning instance.

The row treats actor signals, scheduling, strategies and storage as supplied primitives rather than a ready coding agent. Inspected storage conformance and plugin tests have exact value/dispatch oracles; none were run. BEAM hot code upgrade was not inferred from the language: no wired upgrade mechanism was traced.

## fast-agent

`ToolRunner` is a real programmable turn iterator: low-level hooks may mutate history/request parameters and append messages. It folds managed-process polling context, compacts before follow-ups, calls the provider, plans/discovers tool batches, and saves resumable checkpoints. Parallel/fanin and evaluator-generator workflows are separate callable agent programs. The evaluator refines **responses** and returns the best rated response; that scope must not be promoted to harness autoresearch.

Persistent background shells are wired into the native tool path. Creation allocates private records; launch makes an exclusive claim and starts a detached supervisor with inherited, unpersisted environment. The supervisor owns a new process group, bounded output retention, heartbeat/status and durable stop request. Resume attaches an existing session-linked process to its original or fallback runtime and reports unavailable/unattached states. It does not replay the command. Closing the harness deliberately leaves durable processes available (`tools/shell_runtime.py:2818–2875,2970–3025`, `session/durable_processes.py:44–108`). ## smolagents

A `CodeAgent` model response becomes parsed Python, then the native `python_interpreter` action invokes a retained executor. Local execution walks AST nodes against persistent state/functions/tools; tools and variables are sent at each `run`. Conversation `reset=True` resets memory/monitor, **not the executor dictionary** (`agents.py:436–500`, `local_python_executor.py:1688–1768`). JSON tool calls run threaded, yield completion order, and then store observations sorted by call ID. Managed agents are synchronous task/report callables; remote code executors explicitly reject them.

The local executor says it is not a security sandbox. Its timeout uses `future.result(timeout=...)` inside a `ThreadPoolExecutor` context. It cannot kill the running worker; ordinary waiting context-manager exit also means the exception path does not establish prompt deadline return. Docker execution starts its own authenticated Jupyter kernel/container, executes over websocket, and stops/removes them at cleanup; it is not leasing an existing shared kernel. ActionStep captures inputs/model response/code/error/timing and state projection, but print/results can already be truncated and model output gets a closing code tag added. `save` exports agent/tool code/configuration, ignoring callbacks and checks, and omits live computation heap. These are useful programmable code/action mechanisms, with clear state and ownership limits. ## rlm

The model receives a short execution scaffold while the real input is `context_N` in a REPL. Python can inspect/decompose it, call registered plain models or recursive RLM children, and set an answer-ready dictionary. Each completion starts a new host handler; persistent mode repoints the retained environment at that handler and appends context. `context`/`history` aliases normally point at the first version; later versions remain addressable (`core/rlm.py:225–298`, `environments/local_repl.py:258–490`). This is concrete model-controlled code orchestration, not merely selectable providers.

Persistence is retention of the same owned environment. Close cleans local state, subprocess kernel or owned Docker container; there is no arbitrary heap serialization/rebuild reattachment. Compaction stores formatted trajectory segments/summaries in REPL history and replaces provider context. Optional logger retains iteration prompts/text/code/results/subcall projections, while `locals` serialization is not an object image (`core/types.py:188–229`). Local execution also swaps process-global output/cwd under a per-instance lock, so nonisolated REPL instances are not universal independent hosts.

A key inspected race test deliberately starts a slow subcall from cell A, times A out, then executes B while A's host callback completes. B must not inherit A's completion. The broker rejects new work at shutdown but explicitly allows already-running callbacks to finish; `drain` discards stale-cell records (`environments/ipython_repl.py:257–284`, `tests/test_ipython_repl.py:633–662`). This is useful attribution isolation, **not** refit quiescence or complete original event custody. Arconaut should retain late-event originals even when suppressing them in a later context. Eight operation groups, all 23 cells and three inspected oracle scopes are saved; no downloaded code/kernel/provider was run.

## bub

Bub makes the entire inbound turn a plugin pipeline: resolve session, load state, build prompt, model, finally save, render and dispatch. Independent interception hooks can rewrite model/messages or finish early, chain effective tool arguments, replace/deny before handlers and mutate results afterward. Exact `ran:safe-ls` test confirms transformed arguments actually execute (`framework.py:150–208`, `hooks/interception.py:124–211`, `tests/test_agent_hooks.py:203–216`). Native commands and model tools share implementations; session model/reasoning/code-mode settings explicitly activate on the **next turn** and persist as tape events.

Code-mode `run_code` compiles full Python/top-level await in a **fresh subprocess**, with async structured tool RPC. Pending host-call tasks are canceled/gathered on done/failure, and the process group is killed/reaped in finally; variables are not retained between actions. Native `bash` differs: foreground timeout returns a live background handle, with output/kill and scoped cleanup. A gated spawn test checks shutdown stays unresolved until the pending spawn finishes and is then terminated (`builtin/codemode/code_runner.py:45–86,107–142`, `tests/test_shell_manager.py:221–259`). These are concrete owned work lifetimes, not shared-kernel or executable refit continuity.

Tape selection defaults to **after** the last anchor. The handoff stores summary in the anchor state, but that anchor is excluded by the query, and the default selector ignores the handoff event. Overflow handoff records only reason/error before retrying the original prompt; a boundary does not itself supply a model-visible substantive summary (`tape.py:148–177,291–329`, `store.py:180–213`, `builtin/agent.py:350–380`). Alternate selectors and tape search can repair the projection; original custody remains bounded: fork redacts nontext inputs, readers skip malformed rows, posthooks change results before recording, temporary forks are discarded, and failed spill returns preview. The fork child query also omits text/date filters applied by its parent store. Successful oversized text spill retains UTF8 chunks/manifest separately from bounded view, and archive test checks both main and sidecar references. The strongest shared lesson is to keep **intent, admitted action, external effect, observed result, durable settlement, and model-visible projection** distinct. Restate fencing and internal journal/state commit are strong platform guarantees without magically settling an external closure. Windmill job completion is a service transaction after script effects. Fast Agent's one-launch records and supervisor attach existing work instead of replaying it. Dagger and Jido preserve logical identity/state while deliberately limiting what is restored. Arconaut should specify the stage of continuity it claims and the unresolved-effect oracle that proves it.

Normal-operation model programming is available at several depths. Dagger can adopt a tool-returned LLM environment; Jido.AI rewrites requests/tools and caller continuation; Letta Code executable mods and Workflow programs are actually wired; Fast Agent exposes mutation-friendly loop callbacks; Bub replaces complete turn stages and executes transformed tool arguments. Smolagents/RLM give the model code-level scheduling and subcall agency. AutoHarness provides many support utilities, but source reachability and an exact input-propagation test are needed before calling them main-loop capabilities. The Bub transformation test and AutoHarness gap provide a discriminating baseline oracle: the handler must receive the admitted **effective** arguments, and both original/effective forms remain attributable.

Original audit is an independent design obligation. Fast Agent archives before destructive context replacement when persistence is enabled and records summarizer request/response plus digest lineage. Windmill's direct test preserves `result` while changing `context`. Letta Code appends compaction transcript entries instead of rewriting a bounded resident tail. These are useful forms of separation. Dagger's explicitly unretained oversized raw output, Docker's ingestion cap, V1 truncation, RLM's stale-callback metadata discard, AutoHarness hashes/size summaries and Bub's fork media stripping each mark a different custody gap. A complete Arconaut audit needs exact originals before these transformations, storage/retention failure behavior, source/effective versions, and canceled/late observations even when those events stay out of the next model context.

Change activation and refit remain separate from ordinary reload. Bub's next-turn settings are close to the agreed default. Letta Code mod generations, Docker toolset restarts, Fast Agent instance rebuilds, Restate deployment compatibility and Jido continuation fingerprints address specific scopes; none establishes Arconaut's complete default of finishing the current turn/affected workflows before activation, or the forced interrupt-and-apply boundary. Smolagents cannot kill a timeout thread; RLM's kernel timeout test explicitly permits a model callback to continue.

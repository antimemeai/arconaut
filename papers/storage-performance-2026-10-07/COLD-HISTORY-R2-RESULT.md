# Cold history R2 ownership delivery

Integrated native slice, not a checkpoint accelerator. RetainedState replay decodes and validates semantics then retains application blobs as checked disk references. Snapshot facts, native SessionStore/CodingEngine restoration, ContextStore history and original handles, AuditLog inspection and application entry points consume fallible owned read buffers. No hidden payload cache exists; eager accessors reject cold references. Exact byte comparisons materialize the compared sides and propagate errors through Result boundaries. Active context and new/in-flight records remain intentionally owned. Non-application retained event blobs remain eager.

Historical reads retain a descriptor owner, bind journal header, selected physical record identity/location/length and frame CRC, and then select the application range. References survive closing the journal and pathname replacement cannot redirect them. The writer lease ends with the journal owner, not its readers. Existing archives remain unchanged. Reading a whole selected frame currently requires a frame-sized buffer; this is not bounded-subrange streaming. CRC validates selected frame bytes, not all untouched history.

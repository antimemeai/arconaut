# Artwork attribution

The arconaut sprite supplied as [arconaut.png](arconaut.png), displayed in this
repository's README and adapted into Arconaut's terminal mascot, comes from
**[Caves of Qud](https://www.cavesofqud.com/)** by
**[Freehold Games](https://www.freeholdgames.com/)**.

All credit for the original artwork belongs to its creators. The game's
[official credits](https://cavesofqud.com/press-kit/#:~:text=Sam%20Wilson) name
**Sam Wilson** for tile art, and **Jason Grinblat** and **Brian Bucklew** as
co-creators. These are the published game credits; this project has not separately
verified the authorship of the individual arconaut tile.

Arconaut's terminal rendering and gentle animation adapt that supplied sprite;
the original character and artwork are from Caves of Qud.
